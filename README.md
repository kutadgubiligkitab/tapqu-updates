# تاپقۇ يېڭىلانمىلىرى

بۇ ئامبار تاپقۇنىڭ قاچىلىغۇچ ھۆججەتلىرىنى ئېلان قىلىش ئۈچۈندۇر. ئەپ ھەر قوزغالغاندا ۋە ھەر 24 سائەتتە بۇ يەردىكى ئەڭ يېڭى نەشرنى تەكشۈرىدۇ.

The Tapqu Windows app checks this public repository for installer updates. Source code lives in the private `kutadgubiligkitab/tapqu` repository.

Each release must be tagged `vX.Y.Z`, attach `TapquSetup-X.Y.Z.exe`, and include a `sha256:` line in the release body.
